## 一、为什么拿自己的博客当宫殿

记忆宫殿（method of loci / 定桩法）能不能用，取决于三件事：空间熟不熟、桩位清不清楚、路线能不能一次走完。自己的博客恰好三样全占：

1. **熟悉度最高**——你每天都在这个页面里进进出出，不用额外"背地图"。
2. **自带档案叙事**——站点的文案本身就是一套库房语言：`PERSONAL ARCHIVE`、`FIELD RECORD`、`KNOWLEDGE ARCHIVE`、`ARCHIVE INDEX`、`READING FILE`、`OPEN FILE`。我们不需要"假装"它是宫殿，它已经在演一座档案馆。
3. **视觉锚点极强**——巨型字、00～05 编号、星座图、卡册、时钟、SCROLL 菱形、初音青 + 芥末绿。桩位越怪、越有颜色、越会动，越难丢。
4. **有动效**——加载遮罩、波浪、翻卡、秒针。凡是"过程类"知识（事件循环、渲染流水线、握手挥手），都可以挂到"会动的东西"上，走一遍就记住顺序。

## 二、方法要点（只用这五条）

1. **空间熟悉 + 路线单向**：宫殿只能朝一个方向走，不折返、不抄近路。本站的天然路线是"加载 → 首屏 → 下滚 → 点进文章 → 切到介绍 → 切到作品 → 写作台 → 404"。
2. **桩位唯一 + 有编号**：一个桩只放一件事，桩与桩不重复。本站现成的编号（00–05、FIELD NOTE 01–06、01/04、02/04、03/04）直接征用为桩号。
3. **图像具体、夸张、会动**：抽象词一律换成"能摸到的东西 + 一个动作 + 一种颜色"。颜色统一用站点的两色：**初音青 = 网络/浏览器**，**芥末绿 = JS/逻辑**。
4. **一图一钩**：每个画面必须能"钩"回一个关键词，钩子是口诀（4–7 字）或首字串。钩不回来的画面等于没建。
5. **间隔重复**：建完当天睡前走一遍，之后 1 天 / 3 天 / 7 天 / 15 天各走一遍。每遍只走路线、不看答案。

> 参考：定桩法的经典描述见 [定桩法·百度百科](https://baike.baidu.com/item/%E5%AE%9A%E6%A1%A9%E6%B3%95/2522466)；关于"宫殿 + 间隔重复"的实践讨论见 [Art of Memory 论坛](https://forum.artofmemory.com/t/how-have-mnemonics-and-memory-techniques-changed-your-life/105349/10)。方法本身不神秘，难的是**桩位与知识点之间的桥要自己搭**——这也是本文档存在的意义。

## 三、四种编码公式

把抽象概念塞进具体空间，只有四种靠谱的桥：

| 知识形态 | 站点里对应的载体 | 例子 |
| --- | --- | --- |
| **结构类**（树、链、层） | 站点已有的"图"：星座图、目录树、卡册叠层、网格 | 星座图 = 原型链；ON THIS PAGE = DOM 树 |
| **过程类**（流水线、循环、握手） | "能走一遍"的动线：楼梯、传送带、秒针、波浪 | 时钟秒针 = 事件循环；加载门 = 请求全流程 |
| **对比类**（三兄弟、两扇门） | "并排"的元素：三个导航项、三块社交按钮、两张卡 | GitHub/Bilibili/邮箱 = call/apply/bind |
| **陷阱类**（坑、边界、报错） | "坏了"的地方：裂缝、漏水、报警灯、锁死的砖 | 绿方块 = const 锁死；浮点数 = 数字牌上多出的尾巴 |

## 五、一轮怎么练（三步，约 12 分钟）

1. **建（5 分钟）**：我给出这一间房的画面脚本，你闭眼按顺序"看见"它们，不背文字，只看画面。
2. **走（3 分钟）**：你出声把这一间房从门口走到出口，每站说出"画面 + 题目 + 三个要点"。我不打断，只记漏。
3. **抽（4 分钟）**：我随机报桩号（"P19 第三张卡"），你立刻答出题目和口诀；再反过来——我报题目，你说桩位。

判定标准：

- **桩位命中**：能不能说出"在哪里"。
- **要点命中**：每条能不能说出 3 个关键词。
- **追问深度**：能不能接住第二层问题（"那如果……呢"）。

漏掉的桩进"裂缝清单"，下一轮优先补。一个房间连续两轮 100% 命中，才进入下一间。

## 七、和网站的联动（可选，后续做）

宫殿可以先只活在文档里。如果后面想让它更"实"，有几个不改视觉、只加数据的方向：

- 给 `blog-content/posts/` 的文章 frontmatter 加 `palace: { room, stake }` 字段，文章页右上角显示"本档案所在桩位 P19"。
- 在文章页右侧 `ON THIS PAGE` 目录下方加一条"宫殿位置"小卡（不动布局，只加一行）。
- 用 `schedule` 按 1/3/7/15 天推送复习提醒。

> 注意：这些属于 `apps/web` 的 UI 改动，真要动手时按仓库规范走三档响应式 + Playwright 契约，并先读 `docs/agents/design-system.md`。本文档阶段不动代码。
