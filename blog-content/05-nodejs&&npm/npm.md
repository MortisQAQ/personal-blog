## npm
### 前缀知识：包与包管理工具

#### 1. 包是什么？

包（package）= 可复用的代码 + 描述文件 + 版本号，它是一个**分发单位**：把一堆代码打包成「可以被发布、被安装、有版本号、声明自己依赖了谁」的东西。

包和模块很深的关系，但关注点不同：

- 模块是**代码的组织单位**（一个文件、一段独立作用域），解决作用域隔离和依赖管理。
- 包是**代码的分发单位**，解决「从哪获取、装哪个版本」。
- 一个包往往包含多个模块，并负责模块的分发。

描述文件在各语言里名字不同，干的事一样——声明入口、版本、依赖、License：`package.json`（JS）、`pom.xml`（Java）、`Cargo.toml`（Rust）、`go.mod`（Go）。

#### 2. 包管理器解决什么问题？

按「没有它会怎样」来理解：

- **复用与分发**：不想重写轮子，但复制粘贴别人的代码没有来源、没有版本、没法更新。需要中心仓库 + 一条安装命令。
- **传递依赖**：A 依赖 B，B 又依赖 C、D……手工把整棵依赖树下载下来是不可能的。需要自动解析依赖图。
- **版本冲突**：项目 A 要 lodash 1.x，项目 B 要 2.x。需要语义化版本 + 版本范围 + 冲突解析规则。
- **可复现**：同事的机器、CI、线上要装出完全一样的依赖。需要 lockfile。
- **环境隔离**：多项目依赖的不同版本共存、互不干扰（`node_modules`、Python 的 `venv`）。
- **安全治理**：漏洞审计（`npm audit`）、私有仓库、供应链攻击。

一句话：包管理器 = 依赖解析 + 版本锁定 + 安装/更新/发布 + 隔离。（npm 还额外带 `scripts` 生命周期脚本，所以它不只是包管理器。）

#### 3. 设计理念

理解包管理器，本质上是理解它在几个矛盾上做的取舍。

**① 声明式，而不是命令式**
你只写「我要什么」（清单里写 `lodash: ^4.17.0`），工具负责算出「怎么装」（一棵满足所有约束的依赖树）。手动敲 `npm install xxx` 是命令式操作，只是辅助；真正的入口是清单文件。

**② 版本号是一份契约**
语义化版本（`MAJOR.MINOR.PATCH`）的价值不在编号规则，而在于：**只要大家都遵守它，升级就可以被自动化**。破坏性变更必须提 MAJOR，工具才敢在 `^` 范围内自动升级。版本范围（`^` 允许 minor 更新、`~` 只允许 patch）就是把「我能容忍多大变动」写成声明。

**③ 确定性优先**
依赖解析的结果取决于当时的仓库状态（谁又发了新版本），是一个**非确定**的过程。lockfile 的作用就是把「这一次解析的结果」固化下来，让每次安装都得到同一棵树——这也是「我这里能跑」问题的正解。

**④ 依赖解析是一道约束求解题，而且可能无解**
一棵树要同时满足所有包的版本范围，冲突严重时没有可行解，这就是**依赖地狱**。各工具解法不同：npm 扁平化 + 允许多版本并存，pnpm 用硬链接共享 + 严格隔离，Go Modules 用最小版本选择（MVS）。

**⑤ 分层：包管理 ≠ 模块系统 ≠ 构建工具**
模块规范（CommonJS / ESM）解决「代码怎么组织」，包管理器解决「代码从哪来」，构建工具解决「代码怎么变成能上线的产物」。但在 Node 里前两者被绑死了：`node_modules` 的目录结构就是 `require` 的查找规则。

**⑥ 中心化与否，是一种治理选择**
npm、PyPI、crates.io 是中心仓库，好处是命名、审计、撤销有统一入口，代价是单点故障和供应链攻击面。Go Modules 反过来——模块路径就是代码仓库地址，直接拉 git，无需注册，但也就没有中心化的治理手段。

#### 4. 其他语言怎么做的（举例）

- **Java**：Maven（2004）+ Maven Central，`pom.xml` 声明式描述，是「声明式依赖管理」的早期样板。
- **Python**：pip + PyPI，清单简单，但隔离要另外靠 `venv` / `conda`。
- **Rust**：Cargo（2014）+ crates.io，`Cargo.toml` + `Cargo.lock`，把「清单 + 锁文件」这套做法做得很标准。
- **Go**：Go Modules（2018），没有中心仓库，`go.mod` + `go.sum`，用最小版本选择算法解依赖。
- **前端**：npm（2010）→ yarn（2016，解决慢和安装结果不确定）→ pnpm（2017，硬链接省磁盘 + 严格隔离）。
- 另外还有系统级包管理器（`apt` / `brew` / `winget`），管的是操作系统上的软件，和语言包管理器不是一回事。
