## 前缀知识：递归
https://labuladong.online/zh/algo/essential-technique/understand-recursion/
可以这么理解递归：递归是用来遍历树这个数据结构的一种方式。
递归的特征：一个函数自己调用自己。
为了避免无限循环，递归必须有对基础形态的返回。
递归的树不一定是二叉树。
## 概念
从一个初始状态出发，经过一系列状态转移，到达最终状态
（通俗来讲：从一个起点触发，经过一系列路径,到达终点。）
### 什么是状态？
首先：我们需要把问题用数学进行描述。
把问题用数学描述，是算法领域的一个通用方法，不只是动态规划问题用到这一方法。
简单的：斐波那契数列f(n)表示第n个斐波那契数。
复杂的：围棋一种可能的局面。围棋一共有15*15个点，有白棋、黑棋、空三种状态。
用数组pos描述围棋一种可能的局势：
for pos[x,y] in pos,pos[x,y]属于{白棋、黑棋、空}这一集合。
状态：用数字描述的一种局面。
比如：
问题：求斐波那契数列的第n项，dp(n)表示第n个斐波那契数的值。
问题：求围棋某种局面下，黑方的目数。状态：dp(pos[x,y])=目数。
### DP 的目标值与状态的关系
状态某种意义上就等于子问题。
状态的dp值，就是某个子问题的最优解。
而最终的目标值，一定可以通过子问题的最优解来得到。
不是“不确定”，而是：**给定一个具体输入后，DP 的目标值在数学上是确定的；不确定的往往只是“达到这个目标的方案/路径”可能有多个。** DP 计算的就是这个确定值。

可以把 DP 看成定义了一个函数：

\[
F(\text{输入}) = \text{目标值}
\]

状态图只是这个函数的计算结构。图中从初始状态到终止状态可能有很多条路径，每条路径对应一种决策方案，路径的代价/收益可能不同。但 DP 最后做的是把这些路径值用某种方式聚合起来，例如：

- 最优化：取 \(\min\) 或 \(\max\)
- 计数：求和
- 概率/期望：按概率加权
- 博弈：交替取 \(\max/\min\)

聚合之后得到的通常是一个确定值。

## 状态和目标值的关系

设状态集合为 \(S\)，每个状态 \(s\) 有一个 DP 值：

\[
dp[s]
\]

它的含义是：

> \(dp[s]\) 是状态 \(s\) 所代表的那个子问题的答案。

例如：

- 最短路中，\(dp[s]\) 可以表示从 \(s\) 到终点的最短距离；
- 背包中，\(dp[i][c]\) 表示前 \(i\) 个物品、容量 \(c\) 时的最大价值；
- 区间 DP 中，\(dp[i][j]\) 表示区间 \([i,j]\) 的最优解；
- 计数 DP 中，\(dp[s]\) 表示到达状态 \(s\) 的方案数。

递推关系定义了状态值之间如何相互决定：

\[
dp[s] = \bigoplus_{s \to t} \bigl(w(s,t) \otimes dp[t]\bigr)
\]

其中 \(\bigoplus\) 可能是 \(\min,\max,\sum\)，\(\otimes\) 可能是 \(+,\times\) 等。边界条件给出若干基础状态的值。给定输入后，状态、转移、边权、边界都确定了，所以所有 \(dp[s]\) 也被确定，最终目标值也被确定。

最终目标值通常和状态的关系是以下几种之一：

1. **就是某个特定状态的值**  
   例如：
   \[
   ans = dp[\text{目标状态}]
   \]
   如编辑距离的 \(dp[n][m]\)，背包的 \(dp[n][C]\)。

2. **是所有终止状态中的最优值/聚合值**  
   例如 LIS：
   \[
   ans = \max_i dp[i]
   \]
   或者对所有状态的DP值求sum等。

3. **是初始状态的值**  
   如果定义 \(dp[s]\) 为“从状态 \(s\) 出发到目标的最优值”，那么：
   \[
   ans = dp[\text{初始状态}]
   \]

4. **通过虚拟起点/终点变成某个状态的值**  
   例如加一个虚拟终点，把所有候选状态连到它，再取 \(\min/\max/\sum\)。这样最终答案仍然可以看成某个虚拟状态的值。

所以，目标值不是独立于状态的神秘东西，它本质上就是：  
**最终问题所对应的那个状态，或者若干状态聚合后的 DP 值。**

## 为什么会有“不确定”的错觉？

因为状态图里路径很多，方案很多。比如数字三角形，从顶到底有很多条路径，每条路径和不同；背包有很多种选法；编辑距离有很多种操作序列。  
但 DP 不关心你具体走哪条路径，它只关心这些路径聚合后的结果：

- 最大和是多少；
- 最大价值是多少；
- 最短编辑距离是多少；
- 方案总数是多少。

所以：

- **目标值**：通常唯一确定。
- **达到目标值的方案**：可能不唯一。
- **计算之前**：你不知道目标值，但它是确定的，DP 就是去求它。

如果同一状态对应的不同历史会导致未来不同，而你没有把这些信息放进状态里，那么 DP 会出错。这不是目标值不确定，而是**状态设计不充分**。正确 DP 要求状态满足“无后效性”：给定当前状态，未来最优值与如何到达这个状态无关。

## 一句话总结

> DP 的目标值在给定输入下是确定的；状态是子问题的抽象，\(dp[s]\) 是该子问题的答案；最终目标值就是某个最终状态的值，或若干终止状态值的 \(\min/\max/\sum\) 等聚合。路径和方案可能多，但目标值是聚合后的确定结果。
### 状态转移
状态转移：从一个局面到另一个局面。
求：最优值（如最短路径）、概率等。
动态规划两种解法：自顶向下、自底向上
自顶向下：通过递归算出最终答案，重点：给递归树剪枝，避免重复计算。
自底向上：基于迭代，算出最终答案。
