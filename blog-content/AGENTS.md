# AGENTS.md

## 项目定位

本仓库是面向**完全零基础学习者**的前端工程师教程与求职知识库。

目标不是零散收集八股文，而是建立一张从基础认知到求职表达的知识网络，覆盖：

- Web 开发基础认知；
- HTML / CSS / JavaScript / TypeScript；
- 浏览器、网络、构建工具、Node.js、React；
- 数据结构与算法；
- 前端工程化与性能优化；
- 面试题、项目经历表达、简历材料；
- AI 开发、AI 辅助工程实践等非传统前端但求职可能用到的内容。

所有文档都应服务于一个目标：帮助读者从零开始，逐步理解前端工程师需要掌握的知识，并能在面试和实际项目中表达清楚。

## 总体写作原则

1. **一律使用中文编写。**
2. **面向零基础读者。** 不默认读者已经理解计算机、网络、浏览器、工程化等概念。
3. **先讲本质，再讲细节。** 每篇文档先回答“它是什么、为什么需要它、解决什么问题”，再进入语法、API、原理或面试表达。
4. **保持精炼。** 保留核心概念和关键例子，避免把一篇入门文档写成资料堆叠。
5. **用例子降低抽象成本。** 例子应贴近前端开发、真实业务或面试场景。
6. **不要孤立写文档。** 每篇教程都应尽量说明它和仓库中其他知识的关系。
7. **避免无意义术语堆砌。** 出现专业词时，要解释它处在哪一层抽象、解决什么问题。

## 目录约定

- **前端内容一律放在 `front-end/` 下**，按 `01-html / 02-css / 03-javascript-typescript / 04-react / 05-构建工具` 的子目录归档，不再在根目录新建零散技术目录。
- **公共底座保持中立**：`0-Web开发基础知识/`、`04-algorhythm/`、`06-互联网是如何工作的/` 前后端共用，不归入任何一端。
- **`posts/` 是站点唯一发布源**，其余目录不参与构建；移动或重命名这些目录不影响线上文章。
- **跨目录引用用相对链接**，目录内用数字前缀表示阅读顺序。
- 后续做全栈学习时，按同一口径新建 `back-end/` 等根目录，不要往前端目录里塞后端内容。

完整目录说明见 [README.md](./README.md)。
